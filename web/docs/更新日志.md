## 📝 更新日志

[1.2.0] - 2026-10-10
- 增加 ComfyUI Nodes 2.0 模式支持，根据当前模式自动选择对应的功能实现，支持页面内切换模式。
- 默认模式与 Nodes 2.0 模式分别放在 default、nodes2 文件夹内，各自包含完整的 8 个功能文件；设置文件集中在 settings 文件夹内。
- Nodes 2.0 模式下，对齐、拉伸和自动布局按节点实际显示尺寸计算，支持嵌套节点组选择，替换节点使用 DOM 高亮。
- 修复 Nodes 2.0 模式下添加节点菜单、收藏节点菜单的鼠标定位问题，以及重复自动布局时的位置偏移问题。
- 修复替换节点取消后的回调残留问题，并在切换模式时清理快捷键监听器、面板、菜单和高亮。
- 移除未启用的 better_search.js 搜索功能文件。

[1.1.2] - 2026-03-21
- 修复“‘自动布局’在对选中节点执行自动排布时，会同时把选中节点所在的节点组一起排布”的bug

[1.1.1] - 2026-03-20
- “自动布局”算法更新：支持对节点组的自动排布
- 调整“自动布局”的间距默认值。
- 修复了“自动布局”垂直间距小于30时实际间距为0的bug

[1.1.0] - 2026-03-20
- “自动布局”算法更新：引入 ASAP (As Soon As Possible, 尽可能早 / 起点对齐) 策略；支持起点对齐（保持同源分支起点整齐）或终点对齐（强推末端节点对齐）。算法会根据策略智能推导节点深度。
- “自动布局”多端口连线的上下乱序问题：当一个节点上有多个输入和输出端口时，按照端口从上到下的顺序依次上下排列节点

[1.0.9] - 2026-02-03
- "快速连线"，增加了对“端口为多个类型”节点的匹配连接。

[1.0.8] - 2026-02-02
- 调整“快速连线”评分权重策略，从“惩罚机制”修改为“奖励机制”。
- 增加“快速连线” Ctrl+Shift+Alt+F 清理单个节点连线时，暴力断开该节点的所有输入和输出连线。

[1.0.7] - 2026-01-31
- 修复“替换节点”进入替换状态后，打开搜索框输入时，会自动退出的bug
  
[1.0.6] - 2026-01-29
- "替换节点"的默认参数调整：填充为0，描边为1；
- 在设置中添加"恢复默认参数"的设置项
- "对齐面板"的水平分布间距、垂直分布间距，输入值增加了内存变量，能够继续使用上一次输入的数值，且在浏览器刷新后和ComfyUI重启后，会恢复默认值（在设置中设定的值）。

- <修复：“自动布局”后节点依旧在当前位置>
- <“快速连接-一对多”时总是把一个端口输出给每个节点>

[1.0.4] - 2026-01-28
- <自定义设置>：可以在设置中设置每个功能
- <选择相同节点>：Shift+A，选择画布上相同的节点。
- <自动布局>：Alt+L，根据流开始或结束的节点，排列布局。
- <快速连线>：F，快速连接选择的节点（根据位置）
- <替换节点>：Shift+R，替换选中的节点（可替换多个）
