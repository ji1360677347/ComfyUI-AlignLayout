## 📝 更新日志

[1.4.3] - 2026-10-11
- “添加节点菜单”和“收藏节点菜单”支持逐级记忆定位：一级记忆分组对准鼠标，子菜单随悬停逐级展开，并将记忆的子分组与父分组水平对齐，不一次展开整条路径。
- 每个分组分别保存上次实际展开的子分组，两个菜单独立保存本地记录，兼容旧版一级分类记录；记忆项不存在时使用普通菜单定位。
- 保留鼠标滚轮调整菜单上下位置的操作，再次移到同一父分组时不重置已展开子菜单的位置。
- 沿用“记住上次分类”开关，关闭时不应用或保存各级记忆；默认模式与 Nodes 2.0 模式同步更新。

[1.4.2] - 2026-10-11
- 在“添加节点菜单”和“收藏节点菜单”设置中分别增加“新增节点跟随鼠标”开关，默认开启，两个菜单独立控制。
- 开启时，节点半透明跟随鼠标，左键放置，右键或 Esc 取消；关闭时，直接放在唤出菜单时的鼠标位置。
- 插件菜单不再依赖 ComfyUI 搜索框的跟随光标设置；默认模式与 Nodes 2.0 模式同步更新，恢复默认设置时重新开启跟随鼠标。

[1.4.1] - 2026-10-10
- “添加节点菜单”和“收藏节点菜单”接入 ComfyUI 原生节点放置流程：节点半透明跟随鼠标，左键确认放置，右键或 Esc 取消添加。
- 沿用 ComfyUI 的“新增节点跟随光标”设置；关闭后，节点仍直接添加到唤出菜单时的鼠标位置。
- 默认模式与 Nodes 2.0 模式同步更新，支持子图内放置，并兼容原有的替换节点流程。

[1.4.0] - 2026-10-10
- “添加节点菜单”移除“首选分类列表”设置，改为自动识别包含 ComfyUI 官方节点的分组。
- 一级菜单依次显示官方分组、纯第三方分组和 Others；相同分类路径合并显示，官方分组内保留同路径的第三方节点。
- 官方节点按节点类实际定义的文件识别，修复 Creative Lab 等直接注册节点因来源字段默认为 nodes 而被误判为官方节点的问题。
- 各区域内按名称排序，手动置顶仅调整所在区域内的顺序，Others 始终位于最后。
- 默认模式与 Nodes 2.0 模式同步更新；更新后需重启 ComfyUI 并刷新页面，使后端识别逻辑生效。

[1.3.0] - 2026-10-10
- 精简对齐面板：移除底部控制栏和原均匀分布功能，将垂直、水平指定间距分布放在环形菜单左下、右下，自动布局按钮移至圆心，并保留随鼠标移动的方向箭头。
- 调整指定间距胶囊的高度、数值宽度及内部留白，默认垂直、水平间距由 50 改为 10；点击按钮或按 Enter 使用输入值，甩动使用设置中的默认间距。
- 环形菜单八个方向均支持自定义功能，简化上、下、左、右的设置名称。
- 在默认间距设置后增加指定间距分布的对齐选项：水平支持上对齐、水平居中、下对齐，默认上对齐；垂直支持左对齐、垂直居中、右对齐，默认左对齐。分布时保持锚点节点位置不动。
- 默认模式与 Nodes 2.0 模式同步更新；修正 Nodes 2.0 指定间距分布的尺寸计算，按节点实际显示尺寸保持间距准确。

[1.2.1] - 2026-10-10
- “替换节点”的搜索框改用与双击画布相同的入口，默认模式和 Nodes 2.0 模式均遵循 ComfyUI 当前的搜索框设置。
- 修复新版搜索框开启“节点跟随鼠标”时替换节点的位置问题，保留原节点的位置、参数和连线。
- 修复 Nodes 2.0 模式下替换状态的发光范围和强度偏大问题，改用 Canvas 绘制，统一两种模式的高亮模糊、描边和缩放规则。

[1.2.0] - 2026-10-10
- 增加 ComfyUI Nodes 2.0 模式支持，根据当前模式自动选择对应的功能实现，支持页面内切换模式。
- 默认模式与 Nodes 2.0 模式分别放在 default、nodes2 文件夹内，各自包含完整的 8 个功能文件；设置文件集中在 settings 文件夹内。
- Nodes 2.0 模式下，对齐、拉伸和自动布局按节点实际显示尺寸计算，支持嵌套节点组选择，替换节点使用 DOM 高亮。
- 修复 Nodes 2.0 模式下添加节点菜单、收藏节点菜单的鼠标定位问题，以及重复自动布局时的位置偏移问题。
- 修复替换节点取消后的回调残留问题，并在切换模式时清理快捷键监听器、面板、菜单和高亮。
- 移除未启用的 better_search.js 搜索功能文件。

[1.1.0] - 2026-03-20
- “自动布局”算法更新：引入 ASAP (As Soon As Possible, 尽可能早 / 起点对齐) 策略；支持起点对齐（保持同源分支起点整齐）或终点对齐（强推末端节点对齐）。算法会根据策略智能推导节点深度。
- “自动布局”多端口连线的上下乱序问题：当一个节点上有多个输入和输出端口时，按照端口从上到下的顺序依次上下排列节点
