## 📝 更新日志

[1.6.0] - 2026-10-11
- 新增独立的“划线断开”功能：按住 Ctrl+鼠标右键划过连线即可断开，支持曲线、折线和重路由连线，一次划线操作可整体撤销。
- 按住 Ctrl 时，鼠标接近连线会渐变高亮，离开或松开 Ctrl 后恢复；设置中可独立开关功能、调整高亮颜色和发光强度。
- 新增“端口连接菜单”：按住 Ctrl+鼠标左键从输入或输出端口拖动，松开后列出当前画布中可连接的节点端口，支持搜索、直接拖到兼容端口连接、替换已有连接、取消和撤销。
- 连接菜单按节点合并多个端口，使用当前语言的端口名称，统一 12px 字体和 14px 行高；节点编号等宽对齐，使用小箭头 ▸，区分节点信息与端口文字颜色，并调整选项间距和内边距。
- 连接菜单宽度随内容调整，最大 360px，窄窗口自动缩小；过长文字显示省略号，悬停可查看完整名称。
- 连接菜单增加实时节点预览：悬停选项时显示对应节点及附近连线，高亮目标端口并展示连接状态；预览不移动画布、不改变节点选中状态，空间不足时自动调整预览位置。
- 默认模式与 Nodes 2.0 模式同步支持以上功能及子图内操作；切换模式、关闭功能或取消操作时清理菜单、预览和高亮。

[1.5.0] - 2026-10-11
- “快速连接”拆分清除连线操作：Ctrl+Shift+Alt+F 仅清除选中节点之间的内部连线，Shift+Alt+F 清除选区与外部节点之间的输入、输出连线；单选时前者不做操作，后者断开该节点全部连接。
- 修正端口匹配设置的名称和说明，改为“类型兼容，名称优先”和“仅类型兼容”；类型判断统一使用 ComfyUI 原生规则，支持原生通配、多类型和特殊端口的兼容判断。
- 优化连续按 F、Shift+F 的端口轮询：按兼容端口切换，名称评分不再覆盖轮询顺序；F 在单输入兼容组内切换来源，Shift+F 切换来源的兼容输出，并保留一对多的分配与广播行为。
- 修复混合类型输入干扰轮询的问题：K 采样器连接完成后，连续按 F 每次交换正、负条件，模型和 Latent 连接保持不变。
- 仅在原生连接成功后记录端口占用并推进链式连接；连接被拒绝时尝试下一个候选，强制连接和轮询失败时保留原连接，非强制轮询保留选区外接入的连线。
- 默认模式与 Nodes 2.0 模式同步更新，支持子图内操作；同步更新快捷键、匹配设置和轮询说明。

[1.4.4] - 2026-10-11
- 将“添加节点菜单”和“收藏节点菜单”的 5 个数据文件合并为 ComfyUI/user/AlignLayout/menu_data.json，统一保存共享收藏及两个菜单各自的置顶顺序、逐级分类记忆。
- 首次使用新版时自动迁移旧记录，核对写入成功后删除旧文件，保留原有收藏、置顶和分类记忆，并兼容旧版一级分类记录。
- 后端统一更新发生变化的数据部分，通过写入锁和临时文件替换保护数据，避免两个菜单更新时互相覆盖。
- 同步更新数据存储与迁移说明；功能开关、快捷键和外观设置仍由 ComfyUI 设置系统保存。更新后需重启 ComfyUI 并刷新页面，使新的后端存储逻辑生效。

[1.4.3] - 2026-10-11
- “添加节点菜单”和“收藏节点菜单”支持逐级记忆定位：一级记忆分组对准鼠标，子菜单随悬停逐级展开，并将记忆的子分组与父分组水平对齐，不一次展开整条路径。
- 每个分组分别保存上次实际展开的子分组，两个菜单独立保存本地记录，兼容旧版一级分类记录；记忆项不存在时使用普通菜单定位。
- 保留鼠标滚轮调整菜单上下位置的操作，再次移到同一父分组时不重置已展开子菜单的位置。
- 沿用“记住上次分类”开关，关闭时不应用或保存各级记忆；默认模式与 Nodes 2.0 模式同步更新。

[1.4.2] - 2026-10-11

- 开启时，节点半透明跟随鼠标，左键放置，右键或 Esc 取消；关闭时，直接放在唤出菜单时的鼠标位置。

[1.3.0] - 2026-10-10
- 精简对齐面板：移除底部控制栏和原均匀分布功能，将垂直、水平指定间距分布放在环形菜单左下、右下，自动布局按钮移至圆心，并保留随鼠标移动的方向箭头。
- 调整指定间距胶囊的高度、数值宽度及内部留白，默认垂直、水平间距由 50 改为 10；点击按钮或按 Enter 使用输入值，甩动使用设置中的默认间距。
- 环形菜单八个方向均支持自定义功能，简化上、下、左、右的设置名称。
- 在默认间距设置后增加指定间距分布的对齐选项：水平支持上对齐、水平居中、下对齐，默认上对齐；垂直支持左对齐、垂直居中、右对齐，默认左对齐。分布时保持锚点节点位置不动。
- 默认模式与 Nodes 2.0 模式同步更新；修正 Nodes 2.0 指定间距分布的尺寸计算，按节点实际显示尺寸保持间距准确。
