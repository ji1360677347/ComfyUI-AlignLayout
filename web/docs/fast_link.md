## 🔗 快速连接 (Fast Link)

**ComfyUI Fast Link** 是一个旨在提升节点连接效率的纯前端插件。它通过智能的空间排序算法和快捷键逻辑，帮助用户实现极速的多对一、一对多、链式连接以及端口切换等操作。

### 🎹 快捷键速查表

> 注意：以下快捷键中的 F 为默认设置，你可以在 ComfyUI 设置面板中自定义为主键（例如改 为 J 或 K）。
> 

| 快捷键 | 模式名称 | 单次按下行为 | 多次连续按下行为 (轮询) |
| --- | --- | --- | --- |
| **`F`** | **多对一 (汇聚)** | 将左侧/上方所有节点的输出，连接到最右侧/下方节点的输入。 | **切换终点接口**：各兼容组独立轮询目标输入；组内只有一个可用输入时轮询兼容的来源。 |
| **`Shift + F`** | **一对多 (智能广播)** | 将最左侧/上方节点的输出连接到其余节点。**智能分配**：若有多个可用输出端口，会尝试分别连接到不同目标；否则广播同一端口。 | **切换起点接口**：在源节点的不同输出端口间轮询切换。 |
| **`Ctrl + F`** | **强制多对一** | **强制**将左侧所有节点连接到终点（会断开旧连接）。 | **切换源节点**：在左侧的源节点列表中依次切换，每次只连接一个源到终点。 |
| **`Ctrl + Shift + F`** | **强制一对多** | **强制**将起点节点连接到右侧所有节点（会断开旧连接）。 | **切换目标节点**：在右侧的目标节点列表中依次切换，每次只连接起点到一个目标。 |
| **`Alt + F`** | **链式连接** | 按照视觉顺序依次连接节点 (1→2→3→4)。 | *(重新执行连接计算)* |
| **`Ctrl + Shift + Alt + F`** | **清除内部连线** | 仅断开选中节点之间的连线，保留选区与外部的连接；单选时不做操作。 | - |
| **`Shift + Alt + F`** | **清除外部连线** | 断开选区与外部节点之间的所有输入、输出连线，保留选中节点之间的连线；单选时断开该节点全部连接。 | - |

### ⚙️ 设置选项说明

你可以在 ComfyUI 的设置面板中找到 **"AlignLayout > FastLink"** 分类，进行以下配置：

1. **启用 Fast Link 插件 (Enable Fast Link)**
    - 全局开关，一键禁用插件功能。
2. **全局快捷键 (Shortcut Key)**
    - 默认为 `F`。你可以将其修改为任何单字母按键（不区分大小写）。修改后，上述所有组合键将基于新按键生效。
3. **垂直堆叠判定阈值 (Vertical Stack Threshold)**
    - **默认值 0.8**。
    - 控制“多对一”和“链式连接”时的排序逻辑。只有当两个节点的**水平重叠部分**超过较小节点宽度的 **80%** 时，插件才会认为它们是“垂直排列”的（按上下排序）；否则视为“水平排列”（按左右排序）。
    - *调小此值（如 0.5）会让错位摆放的节点更容易被判定为垂直列。*
4. **模式重置超时 (Mode Reset Timeout)**
    - **默认值 2000ms**。
    - 当你连续按键进行“接口切换”或“节点轮播”时，如果停止操作超过这个时间，计数器会重置。下次再按将重新开始，而不是继续切换。
5. **端口匹配优先级 (Port Match Priority)**
    - **类型兼容，名称优先**：默认值。使用 ComfyUI 原生类型兼容规则，优先连接同名端口，名称不同也允许连接。
    - **仅类型兼容**：使用相同的类型兼容规则，忽略端口名称。
    - 名称评分决定首次连接的优先顺序；连续按键时，按兼容端口轮询，不会因名称评分一直停留在同一端口。

### 🛠️ 详细功能逻辑

### 1. 智能连接策略

- **一对多智能分配 (`Shift+F`)**：
    - 插件不再单纯地将同一个输出端口连接给所有目标。
    - **优先分配本次操作中尚未使用的端口**：如果源节点有多个兼容输出端口，尝试分别连接到不同目标。
    - **广播复用**：本次操作中的可用端口用完后，复用已经成功连接的端口。
- **非强制模式保护**：
    - 第一次按下时，**绝对不会**断开目标端口已有的连线，只会填补空位。
- **强制模式 (`Ctrl+...`)**：
    - 允许替换目标端口的旧连线；由 ComfyUI 原生接口验证并建立新连接。新连接被拒绝时保留旧线，并尝试下一个候选。
- **轮询保护**：
    - 非强制轮询保留选区外节点接入的连线。成功建立新连接后才清理本次替换的选区内旧线；连接失败时保留原连接。

### 2. 清除内部与外部连线

两个快捷键分别处理选区内部和选区边界的连线：

- **清除内部连线 (`Ctrl+Shift+Alt+F`)**：只移除两端都在选区内的连线，外部连接保留。只选中一个节点时不做操作。
- **清除外部连线 (`Shift+Alt+F`)**：只移除一端在选区内、另一端在选区外的连线，包括输入和输出方向。只选中一个节点时，断开该节点全部连接。
- **示例**：A→B→C→D，选中 B、C。清除内部连线只断开 B→C；清除外部连线断开 A→B、C→D，保留 B→C。选区外节点之间的连线在两种操作下均保持不变。
- 一个输出端口同时连接内部和外部节点时，仅移除符合条件的连线，不会将整个输出端口的连接一起断开。

### 🧠 核心算法机制

### A. 视觉列排序 (Visual Column Sort)

- **应用场景**：`F`, `Ctrl+F`, `Alt+F`
- **原理**：利用“垂直堆叠判定阈值”来智能识别你的布局是“横向流”还是“纵向栈”。完美解决了错位布局（半重叠）时的连接顺序混乱问题。

### B. 严格左上排序 (Strict Left Sort)

- **应用场景**：`Shift + F`, `Ctrl+Shift+F`
- **原理**：严格寻找坐标最左（其次最上）的节点作为发射源，符合“广播”操作的直觉。

### C. 端口评分与分配策略 (Port Scoring & Allocation)

- **应用场景**：智能广播与端口匹配
- **类型判断**：调用 ComfyUI 原生 `LiteGraph.isValidConnection()`，与手动连接使用同一套类型规则。
- **首次匹配**：普通兼容端口中，同名端口优先；通配端口优先级较低。“仅类型兼容”模式忽略名称。
- **端口轮询**：`F` 按各输出的兼容输入顺序切换；`Shift+F` 按各输入的兼容输出顺序切换。不兼容端口不参与轮询。不同类型的端口互不干扰，例如 K 采样器的模型、Latent 连接保持不变，两个条件来源在正面与负面输入间轮换。
- **分配与成功判定**：多对一每个输出在本次操作中使用一次；一对多先分配尚未使用的输出，再广播复用。只有原生 `connect()` 返回实际连线后，才记录端口已使用、继续推进链式连接；被拒绝的候选不会占用端口名额。
