## ✂️ 划线断开 (Link Cut)

无需选中节点，按住 **Ctrl＋鼠标右键**，拖动划过连线即可断开。松开右键或 Ctrl 后停止切断，**Ctrl+Z** 恢复整次划动断开的连线。

按住 Ctrl 即可显示接近高亮，无需按鼠标右键：指针距离连线约 12 个屏幕像素时开始渐亮，越接近越亮，按住右键拖动、进入约 4 像素的切断范围时立即断开；仅按 Ctrl 移动不会断开连线。过渡距离约 8 像素，不随画布缩放变化。远离连线或松开 Ctrl 后立即恢复原样，普通鼠标经过时不会高亮。高亮不修改连线本身的颜色或工作流数据。

在 **插件设置 → 对齐布局 (AlignLayout) → 划线断开** 中调整：

- **启用划线断开**：默认开启，独立于快速连线开关。关闭后同时关闭 Ctrl 高亮和划线断开。
- **高亮颜色**：默认 `#66CCFF`，同时用于连线描边和发光。
- **发光强度**：默认 `8`，范围 `0～50`；设为 `0` 时保留颜色高亮，关闭外发光。

支持默认模式和 Nodes 2.0、曲线/直线/折线、画布缩放与子图。使用实际绘制路径检测，快速移动时也检查两次鼠标事件之间的完整轨迹。

同一输出的其他分支保留。划过重叠连线或转接点前的共用路径时，断开命中的所有连接。操作期间显示十字光标，不打开右键菜单、不平移画布；从节点或输入控件内部按下时不启动划线断开。
