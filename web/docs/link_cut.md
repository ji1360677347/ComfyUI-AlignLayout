## ✂️ 划线断开 (Link Cut)

**操作方式**：`Ctrl + 鼠标右键` 从画布空白处开始拖动，划过连线即可断开，无需选中节点。

**划线断开** 用于清理不需要的节点连接。按住 Ctrl 可预先查看连线高亮，按住右键划动时显示鼠标轨迹；一次划动可以断开多条连线，并通过 `Ctrl + Z` 整体恢复。

### ✨ 核心特性 (Features)

- **划过即断**：按住 Ctrl＋右键拖动，命中的连线立即断开。
- **接近高亮**：只按住 Ctrl 移动鼠标，附近连线逐渐亮起，越接近越亮。
- **鼠标轨迹**：划动时显示完整路径，默认白色、粗细 2px，停止划动后消失。
- **独立设置**：可调整轨迹开关、颜色、粗细，以及连线高亮外观和判定距离。
- **整次撤销**：一次划动断开的所有连线作为一次操作撤销。
- **双模式支持**：支持默认模式、Nodes 2.0 和子图内操作。

### 🎹 操作速查表

| 操作 | 效果 |
| --- | --- |
| 按住 `Ctrl`，鼠标接近连线 | 显示渐亮高亮，不断开连线。 |
| 按住 `Ctrl + 右键`，从空白处划过连线 | 断开命中的连线，同时绘制鼠标轨迹。 |
| 松开右键 | 停止断线并清除轨迹；Ctrl 仍按住时继续显示接近高亮。 |
| 松开 `Ctrl` | 停止断线，同时清除轨迹和高亮。 |
| 按下 `Esc` | 结束当前划动；已经断开的连线保留。 |
| 完成划动后按 `Ctrl + Z` | 恢复整次划动断开的连线。 |

### 📖 使用指南 (Usage)

#### 1. 查看并切断连线

1. 将鼠标放在画布空白处，不要从节点主体或输入控件内部开始。
2. 按住 **Ctrl**，移动到需要断开的连线附近，确认高亮位置。
3. 保持 Ctrl 按住，再按住 **鼠标右键**，划过一条或多条连线。
4. 松开右键结束操作；松开 Ctrl 后高亮也会消失。

操作期间光标显示为十字，不打开右键菜单，也不平移画布。快速移动时会检查两次鼠标事件之间的完整路径。

> 提示：仅按住 Ctrl 接近连线不会断线。连线是在划动过程中立即断开的，松开鼠标或按 Esc 只结束操作；需要恢复时，请在结束划动后按 Ctrl＋Z。

#### 2. 高亮范围与切断范围

两个距离均按**屏幕像素**计算，不随画布缩放变化：

- **高亮起始距离**：默认 12px，决定鼠标从多远开始让连线亮起。
- **切断判定距离**：默认 4px，决定 Ctrl＋右键划动路径距离连线多近会将其断开。
- **渐亮过渡**：默认从 12px 到 4px，距离越近越亮；远离连线或松开 Ctrl 后恢复原样。

高亮起始距离至少比切断距离大 1px。例如切断距离设为 10px、高亮距离设为 6px 时，实际高亮起始距离为 11px，设置中的数值保持不变。

#### 3. 多条连线与分支

- 一次划动可以断开多条连线，未命中的其他分支保留。
- 划过重叠连线时，会断开所有命中的连接。
- 划过转接点前的共用路径时，会断开经过该段路径的所有连接；只想断开一个分支时，应划过分叉后的独立路径。
- 节点遮挡区域不参与切断判定，从节点或输入控件内部按下不会启动此功能。

### ⚙️ 设置与自定义 (Settings)

在 **插件设置 → 对齐布局 (AlignLayout) → 划线断开 (Link Cut)** 中调整：

| 设置项 | 默认值 | 范围 / 步长 | 说明 |
| --- | --- | --- | --- |
| 启用划线断开 (Enable Link Cut) | 开启 | 开启 / 关闭 | 总开关，独立于快速连接；关闭时结束当前划动并清除轨迹和高亮。 |
| 高亮颜色 (Highlight Color) | `#66CCFF` | 颜色值 | 连线接近高亮及发光的颜色。 |
| 发光强度 (Glow Strength) | 8 | 0～50 / 1 | 连线外发光的模糊半径；设为 0 时只保留颜色高亮。 |
| 高亮起始距离 (Highlight Start Distance) | 12px | 2～40px / 0.5px | 开始渐亮的距离，实际生效值至少比切断距离大 1px。 |
| 切断判定距离 (Cut Detection Distance) | 4px | 1～20px / 0.5px | 值越大越容易切断连线，与轨迹粗细无关。 |
| 显示鼠标轨迹 (Show Mouse Trail) | 开启 | 开启 / 关闭 | 关闭后隐藏鼠标轨迹，仍可正常断线和高亮。 |
| 轨迹颜色 (Trail Color) | `#FFFFFF` | 颜色值 | 鼠标划动路径的颜色，默认白色。 |
| 轨迹粗细 (Trail Width) | 2px | 1～10px / 0.5px | 按屏幕像素计算，不随画布缩放变化。 |

**生效时机**：高亮颜色、发光强度和两个距离设置立即生效；轨迹开关、颜色和粗细从下一次划动起生效。同一次划动的轨迹样式保持一致。

**设置保存**：由 ComfyUI 设置系统保存，两种模式共用。轨迹和高亮只是临时提示，不写入工作流。

### 🧩 适用范围与操作结束

支持曲线、直线、折线和转接点路径，按当前画布实际绘制的连线进行判定。子图内只操作当前子图的连线。

松开右键或 Ctrl、按 Esc、关闭功能、切换模式或子图、窗口失去焦点、窗口尺寸改变时，当前划动结束并清除轨迹。已经断开的连线通过撤销恢复。

### ❓ 常见问题 (Q&A)

**Q：连线已经高亮，为什么没有断开？**

A：高亮范围比切断范围大。需要从空白处开始按住 Ctrl＋右键划动，并进入切断判定距离内；仅按 Ctrl 悬停不会断线。

**Q：把轨迹调粗，会更容易切断连线吗？**

A：不会。轨迹粗细只改变显示效果；需要调整灵敏度时，请修改“切断判定距离”。

**Q：为什么轨迹消失后，连线仍在高亮？**

A：松开右键后轨迹消失，但只要 Ctrl 仍按住，接近高亮就会继续工作。松开 Ctrl 后高亮消失。

**Q：松开 Ctrl 后，保持右键按住，再按 Ctrl 能继续断线吗？**

A：松开 Ctrl 已经结束本次断线。请松开右键，再从画布空白处重新开始 Ctrl＋右键划动。

**Q：设置中没有看到新增的中文选项？**

A：更新插件后重启 ComfyUI，再刷新页面，加载最新的设置名称和说明。
