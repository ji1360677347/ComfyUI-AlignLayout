## 🔌 端口连接菜单 (Port Connection Menu)

按住 **Ctrl＋鼠标左键**，从节点输入或输出端口拖出并松开，弹出当前画布的兼容端口列表。

- 从输出端口拖出：列出其他节点的兼容输入端口。
- 从输入端口拖出：列出其他节点的兼容输出端口。
- 每个节点显示一项：“#编号 节点名称 ▸ 端口名称（已有连接）”，多个兼容端口在同一项内分行显示，点击对应端口行即可连接。
- 选项统一使用 12px 字体、14px 行高，编号列按菜单中最长的编号等宽排列，节点名称左对齐。同一项内的端口名称上下对齐；节点信息和箭头为灰色，端口名称和连接状态为白色。
- 选项之间没有额外间距，高亮区域与搜索框等宽，文字左右各留 8px 内边距。
- 菜单按选项内容调整宽度，最小 160px 以便使用搜索框，最大 360px；窄窗口左右保留 8px。过长文字显示省略号，悬停可查看完整名称，筛选时保持菜单宽度稳定。
- 悬停端口行或用键盘聚焦时，右侧显示该节点所在画布局部的实时预览，并高亮对应端口，列出当前连接的节点。右侧空间不足时预览移到菜单上方或下方。
- 预览不移动主画布、不改变选中状态，只在悬停期间刷新。读取当前画面和节点 DOM；视野外没有 DOM 的节点按当前图数据显示端口、连线和参数，自定义控件及嵌入式页面使用简化显示。
- 端口名称沿用 ComfyUI 当前语言的显示名称，保留自定义标签；没有翻译时显示原名。端口类型只在菜单顶部显示。
- 排除自身节点，使用 ComfyUI 原生类型兼容规则。子图内只列出当前子图的节点，包含当前视野外的节点。
- 菜单支持滚动和按节点、编号、端口筛选。输入筛选后按 Enter 可连接第一个可用选项。

点击选项后才连接。已占用的输入端口标注“（已有连接）”，选择后替换原有连接；已与当前端口连接的选项不可重复连接。连接被节点拒绝时保留原有连接。

按 Esc 或点击菜单外取消，已有连线保持不变。Ctrl+Z 撤销连接或替换操作。直接拖到兼容目标端口仍然直接连接，不弹出菜单。

不按 Ctrl 或使用 Shift 拖动时，保留 ComfyUI 原有的搜索/推荐弹窗行为。拖动中松开 Ctrl 则取消此次操作。

在 **插件设置 → 对齐布局 (AlignLayout) → 端口连接菜单** 中可关闭此功能，默认开启。默认模式和 Nodes 2.0 分别使用各自目录的独立实现。
