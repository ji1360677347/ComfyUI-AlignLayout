## 🔌 连接助手 (Connection Assistant)

**操作方式**：按住 `Ctrl + 鼠标左键` 从输入或输出端口拖出连线，在目标端口上松开或点击确认。

**连接助手** 用于画布缩小后看不清端口，或目标节点距离较远时接线。可通过 Ctrl 悬停放大节点，也可通过节点菜单寻找目标。放大直接使用主画布上的真实节点，端口、参数和第三方控件沿用原来的显示方式。

### ✨ 核心特性 (Features)

- **三个操作入口**：接线前悬停放大起始节点、拖线时悬停放大目标、从菜单寻找兼容节点。
- **持续待连接**：连线始终跟随鼠标，松开 Ctrl 或在节点主体上松开左键后仍可继续寻找目标。
- **真实端口接线**：在画布上的兼容端口确认，使用 ComfyUI 原生兼容规则，支持替换已有输入连接。
- **自由寻找目标**：待连接时可平移、缩放画布，也可查看没有兼容端口的附近节点。
- **视图恢复**：离开临时放大的节点时返回本轮放大前的视图，完成或取消后返回操作开始前的视图。
- **双模式支持**：支持默认模式、Nodes 2.0 和当前子图内的节点。

### 🎹 操作速查表

| 操作 | 效果 |
| --- | --- |
| 接线前按住 `Ctrl` 悬停节点，不按鼠标按钮 | 默认等待 200ms 后临时放大起始节点。 |
| `Ctrl + 左键` 从输入或输出端口拖出 | 开始待连接，连线跟随鼠标。 |
| 待连接时按住 `Ctrl` 悬停任意节点 | 立即开始定位放大，左键按住或松开均可。 |
| 在画布空白处松开初次拖线的左键 | 打开具有兼容端口的节点菜单。 |
| 悬停菜单项 | 默认等待 200ms 后，将真实目标节点定位到菜单右侧，无需按 Ctrl。 |
| 点击菜单项 | 立即定位该节点，随后仍需选择真实端口确认连接。 |
| 在兼容端口上松开或点击左键 | 确认连接，关闭菜单并恢复原视图。 |
| 待连接时使用中键拖动或 `空格 + 左键` | 平移画布，暂时停止悬停定位。 |
| 在画布上滚动鼠标滚轮 | 缩放画布；菜单内滚轮用于滚动列表。 |
| `Esc` 或鼠标右键 | 取消待连接或临时放大，恢复原视图。 |
| 连接完成后按 `Ctrl + Z` | 撤销本次连接或替换。 |

### 📖 使用指南 (Usage)

#### 1. 接线前放大起始节点

适合缩小画布后看不清起始端口的情况。

1. 将鼠标移到起始节点上，按住 **Ctrl**，不要按鼠标按钮。
2. 默认等待约 **200ms**，主视图临时放大该节点，并显示高亮边框。
3. 保持 Ctrl 按住，从真实输入或输出端口按住左键拖出连线。
4. 松开 Ctrl 后恢复放大前的视图，已经拉出的连线仍保持待连接。

此入口可通过“接线前悬停放大”单独关闭。等待时间可设置；在输入框中编辑或从画布空白处开始 Ctrl＋左键框选时，保留原生操作。

#### 2. 拖线时放大目标节点

适合知道目标大致位置，想查看节点并选择端口的情况。

1. 按住 **Ctrl＋左键**，从起始端口拉出连线。
2. 保持或重新按住 Ctrl，将鼠标移到目标节点上，立即开始定位放大，无需等待。
3. 将鼠标移到兼容端口，松开左键完成连接；如果左键已松开，则点击兼容端口确认。

待连接时可持续按住 Ctrl 在多个节点之间切换；也支持左键一直按住时松开、再次按下 Ctrl。**任意节点都可查看**，包括没有兼容端口的节点和起始节点，但只有其他节点的兼容端口可以确认连接。

松开 Ctrl，或从节点移到空白处后，恢复本轮放大前的视图，连线仍跟随鼠标。移出节点有短暂缓冲，避免定位动画造成误判。直接悬停放大尽量保持鼠标在节点上的相对位置，并按画布边界和侧栏位置调整。

#### 3. 通过菜单寻找目标

适合目标太远，或不知道哪些节点可以连接当前端口的情况。

1. 按住 **Ctrl＋左键**，从端口拖到画布空白处后松开。
2. 菜单列出当前图内具有兼容端口的节点，每个节点一项，格式为 **`#编号 节点名称`**。
3. 悬停某个菜单项，默认等待 200ms 后，主视图将该节点定位并放大到菜单右侧；也可直接点击菜单项立即定位。
4. 将鼠标移到右侧真实节点的兼容端口，点击确认连接，无需继续按住 Ctrl。

悬停切换菜单项时，菜单位置、尺寸和滚动位置保持不变。从菜单移向节点端口时保留当前查看位置，不会因移出菜单而恢复。

**菜单操作**：

- 顶部显示起始节点、起始端口名称和类型。
- 列表仅显示节点编号和名称，同一节点有多个兼容端口时也只列一项，具体端口在真实节点上选择。
- 在搜索框输入节点名称或编号进行筛选；按 Enter 聚焦第一个结果并预览，不直接连接。
- 节点编号等宽排列，名称左对齐；过长名称显示省略号，悬停可查看完整名称。
- 默认字体 12px、行高 14px，行高随字体保持多 2px；文字左右各留 8px 内边距，选项之间没有额外间距。
- 菜单按内容调整宽度，默认最大 360px；窄视图自动缩小，为右侧目标留出空间。

#### 4. 待连接时平移、缩放与取消

拉出连线后，可以松开 Ctrl 和左键再寻找目标。此时连线继续跟随鼠标：

- **平移**：按住中键拖动，或使用空格＋左键抓手。原来的左键仍按住时，也可以直接按下中键或空格开始平移。
- **缩放**：在画布上使用鼠标滚轮。
- **继续定位**：结束抓手操作后，将鼠标移到附近节点并按 Ctrl，立即查看该节点。
- **取消连接**：按 Esc 或右键，清除待连接并恢复原视图。

抓手优先于悬停定位，平移期间不会自动跳到经过的节点。按住空格时显示抓手，平移时显示握住的抓手。**开始抓手平移会关闭节点菜单**，待连接保留；菜单内滚轮只滚动列表。

### 🧭 视图恢复规则

同一次操作分别保留两个恢复位置：

| 场景 | 恢复位置 |
| --- | --- |
| 松开 Ctrl，结束起始节点的临时放大 | 起始节点放大前的位置和缩放。 |
| 待连接时松开 Ctrl，或移出直接悬停的节点 | 本轮临时放大前的位置和缩放，待连接保留。 |
| 手动平移或缩放后，再临时放大并移出节点 | 返回手动调整后的视图。 |
| 连续切换直接悬停的节点 | 沿用本轮放大前的恢复位置。 |
| 从菜单移到目标节点 | 保留当前查看位置，方便选择端口。 |
| 完成连接、取消连接或关闭功能 | 返回本次操作开始前的视图；若先放大起始节点，则返回起始节点放大前的视图。 |
| 节点拒绝连接 | 保留当前查看位置及待连接状态，允许继续选择。 |

临时查看只改变画布位置和缩放，不移动节点、不改变节点选择或参数。只有在兼容端口上确认后才修改连接；输入端口已有连接时，新连接成功后才替换旧线，被拒绝时保留旧线。撤销连接时使用原视图记录，避免回到临时放大的位置。

### ⚙️ 设置与自定义 (Settings)

在 **插件设置 → 对齐布局 (AlignLayout) → 连接助手 (Connection Assistant)** 中调整：

| 设置项 | 默认值 | 范围 / 步长 | 说明 |
| --- | --- | --- | --- |
| 启用连接助手 (Enable Connection Assistant) | 开启 | 开启 / 关闭 | 总开关，关闭时取消待连接并恢复原视图。 |
| 接线前悬停放大 (Source Hover Zoom) | 开启 | 开启 / 关闭 | 控制尚未接线时的 Ctrl 悬停放大，不影响端口拖线或菜单预览。 |
| 拖线时悬停放大 (Target Hover Zoom) | 开启 | 开启 / 关闭 | 控制待连接时的 Ctrl 悬停放大，不影响实际接线或菜单预览。 |
| 预览缩放比例 (Preview Zoom) | 125% | 50～300% / 5% | 画布缩放百分比；原视图更大时保持原缩放，横向空间不足时限制缩放。 |
| 定位动画时长 (Animation Duration) | 180ms | 0～1000ms / 10ms | 平移和缩放动画的时长；设为 0 时立即定位。 |
| 节点高亮颜色 (Node Highlight Color) | `#66CCFF` | 颜色值 | 当前查看节点的边框和发光颜色。 |
| 节点发光强度 (Node Glow Strength) | 8 | 0～50 / 1 | 节点外发光的模糊半径；设为 0 时只保留高亮边框。 |
| 悬停等待时间 (Hover Delay) | 200ms | 0～1000ms / 25ms | 只影响接线前悬停和菜单项悬停，拖线时 Ctrl 悬停仍立即开始定位。 |
| 菜单最大宽度 (Menu Max Width) | 360px | 160～800px / 20px | 菜单仍按内容自适应，窄视图自动缩小。 |
| 菜单字体大小 (Menu Font Size) | 12px | 10～24px / 1px | 行高和内容宽度随字体调整，编号仍等宽对齐。 |

**生效时机**：高亮外观立即更新；调整缩放、动画或已打开菜单的字体、宽度时，更新当前预览并保留待连接。关闭某个悬停入口时，恢复对应的临时视图，其他入口继续可用。

**设置保存**：由 ComfyUI 设置系统保存，两种模式共用。预览缩放是画布的实际比例，例如 125% 表示 1.25 倍标准大小，并非在当前缩放上再乘以 1.25。

### 🧩 兼容与交互范围

- 从输入端口开始时，寻找兼容的输出端口；从输出端口开始时，寻找兼容的输入端口。不允许连接自身节点。
- 菜单包含当前图中视野外的节点；子图内只列出当前子图节点，不跨图接线。
- 放大使用主画布原有节点和控件显示逻辑，端口名称、参数和第三方控件沿用 ComfyUI 的语言与显示。接线期间不编辑参数。
- 折叠节点保持折叠。需要查看具体端口时，请先展开节点再开始操作；高节点可平移查看其余端口。
- 定位时避让侧栏，并按可用宽度限制放大比例。
- 不按 Ctrl 或使用 Shift 拖动端口时，保留 ComfyUI 原有搜索、推荐菜单行为。画布空白处开始的 Ctrl＋左键框选仍为原生操作。
- 关闭功能、切换模式、窗口失去焦点、切换图或起始节点被删除时，清理待连接、菜单与高亮；切换图后不会把旧视图应用到新图。
- 待连接时右键优先用于取消连接，不会同时触发划线断开。

### ❓ 常见问题 (Q&A)

**Q：两处 200ms 等待分别是什么？**

A：接线前 Ctrl 悬停起始节点，以及悬停菜单项，默认都等待 200ms，由“悬停等待时间”控制。已经拉出连线后，Ctrl 悬停画布节点立即开始定位，不使用该等待时间；定位动画时长单独设置。

**Q：松开 Ctrl 或左键后，为什么连线还跟着鼠标？**

A：这是待连接状态，方便远距离寻找目标。在兼容端口上点击或松开左键确认；按 Esc 或右键取消。

**Q：点击菜单项为什么没有直接连上？**

A：菜单项用于定位目标节点。一个节点可能有多个兼容端口，需要在右侧真实节点上选择具体端口确认。

**Q：为什么能放大一个没有兼容端口的节点？**

A：直接 Ctrl 悬停允许查看任意附近节点，便于确认位置。菜单只列出兼容节点；实际确认连接仍要求端口类型兼容。

**Q：节点没有放大到预期比例？**

A：先检查“预览缩放比例”。原视图更大时保持原缩放；侧栏、菜单或节点宽度导致可用空间不足时，会自动降低放大比例。

**Q：设置中没有看到新增的中文选项？**

A：更新插件后重启 ComfyUI，再刷新页面，加载最新的设置名称和说明。
