## 🔌 连接助手 (Connection Assistant)

用于视图缩小后看不清端口，或目标节点距离较远时连接节点。三个入口直接使用主画布上的真实节点，不再创建独立放大窗口、第二画布或网页控件镜像。

- **按住 Ctrl 悬停起始节点**：默认等待约 200 毫秒后临时放大主视图，可从真实输入或输出端口拉出连线。松开 Ctrl 恢复原视图；已经拉出的连线保持待连接。可单独关闭此入口或调整等待时间。
- **Ctrl＋左键从端口拖出连线**：进入待连接状态后，只要按住 Ctrl，鼠标移到任意节点就立即开始定位并放大，没有悬停等待，左键按住或松开都可以。拖线过程中松开 Ctrl，再次按住 Ctrl，也会立即定位鼠标所在节点；保持 Ctrl 按住移动到其他节点可继续切换。不按 Ctrl 时可正常寻找节点，使用抓手期间暂停定位。无需具有兼容端口，可先查看附近节点，再移向真正的目标；待连接时也可查看起始节点。只有在兼容端口上松开或点击才确认连接。松开 Ctrl 或鼠标移出节点到空白处后恢复本次放大前的视图，并保留待连接；移出有短暂缓冲，避免放大过程误判移出。完成或取消连线后恢复最初拖线前的视图。画布空白处开始的 Ctrl＋左键框选仍使用原生操作。
- **Ctrl＋左键从端口拖到空白处，松开**：列出具有兼容端口的节点，每个节点一项，只显示 `#编号 节点名称`。菜单选项悬停后主视图定位并放大目标，默认等待约 200 毫秒，无需按 Ctrl，将其放在菜单右侧。菜单的位置、尺寸和滚动位置保持不变；鼠标从菜单移向目标端口时保留当前视图，也可按住 Ctrl 悬停其他画布节点继续查看。完成或取消后关闭菜单并恢复原视图。

连线持续跟随鼠标。松开 Ctrl 或在节点主体上松开左键不会取消待连接；可以继续寻找目标，再点击兼容端口确认。直接拖到原画布的兼容端口仍可连接。输入端口已有连接时，确认新连接后替换；节点拒绝连接时保留原有连线，并允许继续选择。只有确认连接时才修改工作流，Ctrl+Z 撤销连接或替换。

同一次操作保留最初拖线前的位置和缩放，用于完成、取消以及撤销连接。同时记录每轮临时放大前的视图：手动平移或缩放后，悬停节点再移开会回到调整后的位置，连续切换节点也沿用本轮放大前的位置。放大期间主动平移或缩放时保留手动调整的视图，下一次悬停以此作为恢复位置。节点拒绝连接时保留当前查看位置。Esc、鼠标右键、关闭功能、切换模式、窗口失去焦点或切换图时清理临时状态；切换图后不把旧视图应用到新图。

放大通过主画布平移和缩放实现，使用 ComfyUI 与第三方节点原有显示逻辑；不会移动节点、改变选择或复制控件。插件接线期间不编辑参数。折叠节点保持折叠，选择具体端口前需要展开。定位时避让 ComfyUI 侧栏，按可用宽度限制缩放；高节点可平移查看其余端口。待连接期间可滚轮缩放、鼠标中键或空格＋左键平移，Ctrl 仍按住时也可使用抓手。按住空格显示抓手，平移时显示握住的抓手，节点和网页控件上也保持一致。左键尚未松开时，可直接按下中键或空格开始平移；平移时暂停自动定位，连线继续跟随鼠标，松开抓手后可继续连接。菜单内滚轮仍用于滚动列表。

菜单选项默认使用 12px 字体、14px 行高，节点编号等宽，节点名称左对齐；选项之间没有额外间距，文字左右各留 8px 内边距。菜单按内容调整宽度，默认最大 360px；窄视图会缩小菜单，为右侧目标留出空间。字体大小和最大宽度可设置，行高随字体保持多 2px，内容宽度同步调整。过长名称显示省略号，悬停可查看完整名称。可按节点名称或编号筛选，筛选框按 Enter 聚焦第一个节点项，不直接连接。

端口名称和参数沿用 ComfyUI 的语言与显示。连接使用原生端口兼容规则，不允许连接自身节点；悬停查看不限制端口类型。子图内只选择当前子图节点，菜单也包含视野外节点。默认模式和 Nodes 2.0 使用各自目录的独立实现。

不按 Ctrl 或使用 Shift 拖动端口时，保留 ComfyUI 原有搜索、推荐弹窗行为。

在 **插件设置 → 对齐布局 (AlignLayout) → 连接助手** 中调整：

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 启用连接助手 | 开启 | 总开关，关闭时取消待连接并恢复原视图。 |
| 接线前悬停放大 | 开启 | 控制尚未接线时 Ctrl 悬停节点的放大，不影响端口拖线和菜单选项预览。 |
| 拖线时悬停放大 | 开启 | 控制待连接时 Ctrl 悬停画布节点的放大，不影响实际接线和菜单选项预览。 |
| 预览缩放比例（%） | 125 | 范围 50～300，是画布缩放百分比；原视图更大时保持原缩放，横向空间不足时自动限制。 |
| 定位动画时长（毫秒） | 180 | 范围 0～1000；设为 0 时直接定位，不播放平移、缩放动画。 |
| 节点高亮颜色 | `#66CCFF` | 当前查看节点的边框和发光颜色。 |
| 节点发光强度 | 8 | 范围 0～50；设为 0 时只保留边框，关闭外发光。 |
| 悬停等待时间（毫秒） | 200 | 范围 0～1000，只影响接线前悬停和菜单选项悬停，拖线时 Ctrl 悬停仍立即开始定位。 |
| 菜单最大宽度（像素） | 360 | 范围 160～800；菜单继续按内容自适应，并在窄视图中缩小。 |
| 菜单字体大小（像素） | 12 | 范围 10～24；行高和内容宽度随字体调整，编号仍等宽对齐。 |

以上设置由 ComfyUI 保存，两种模式共用。修改高亮外观立即生效；调整缩放、动画或已打开菜单的字体、宽度时更新当前预览，并保留待连接。关闭某个悬停入口会恢复对应的临时视图，其他入口可继续使用。
